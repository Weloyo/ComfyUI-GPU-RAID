# ComfyUI GPU RAID — распределённая генерация на нескольких GPU

Расширение ComfyUI, которое объединяет вашу локальную видеокарту и облачные GPU
(Kaggle, Colab Pro, RunPod/Vast, второй ПК) в один «RAID-массив» для генерации
изображений и видео.

**Pull-архитектура:** мастер (ваш ПК) сам опрашивает воркеров и забирает
результаты. Ваш компьютер **никогда не выставляется в интернет**; воркеры
защищены токеном (`X-GPURAID-Token`), туннели — только на стороне облака.

## Что умеет

| Режим | Что делает | Ускорение |
|---|---|---|
| **Stripe** | N вариантов одного промпта (разные сиды) раздаются всем GPU из общей очереди (work-stealing: быстрая карта берёт больше) и собираются в один батч | ≈ линейное по числу GPU для батча |
| **Offload** | Весь workflow (например, видео Wan/LTX) уходит целиком на выбранный воркер, прогресс транслируется, результаты возвращаются в `output/gpuraid/` | освобождает локальную GPU |
| **Tiled Upscale** | Тайлы одного большого изображения апскейлятся параллельно на всех GPU и склеиваются с фезером | реальное ускорение одной картинки |
| **Long Video** | Видео любой длительности из коротких сегментов: последовательная цепочка (i2v-продолжение) или параллельные FLF2V-сегменты между ключевыми кадрами + редактор (промпты/порядок/трим/кроссфейд/перегенерация/экспорт) | параллельно в режиме keyframes |
| **«Сценарист»** ([docs/STORY.md](docs/STORY.md)) | Пишете сюжет — LLM разбивает его на сегменты с редактируемыми промптами, воркеры параллельно рендерят ключевые кадры (T2I) и FLF2V-сегменты, итог склеивается в одно видео любой длины | параллельно по кадрам и сегментам |
| **Pipeline** ([docs/SHARDING.md](docs/SHARDING.md)) | Одна модель, которая не влезает в один GPU (MiniMax H3 ≈ 40 ГБ весов), режется ПО КОМПОНЕНТАМ: энкодер+семплинг на большой облачной карте, VAE-декод локально; промежуточные тензоры едут бандлами | доступ к моделям «не по размеру» вашей GPU |

Жизненный цикл облачных воркеров автоматизирован ([docs/LIFECYCLE.md](docs/LIFECYCLE.md)):
режимы ⚡ Держать / 🌙 Эко (автостоп по простою) / ⏻ Сразу гасить / 🏠 Только
локально, автоподключение воркеров через приватный GitHub Gist (без копипасты
строк) и автозапуск Kaggle-кернела по кнопке. Квота не горит впустую: простой —
воркер гасится сам (Colab: `runtime.unassign()`, Kaggle: конец batch-сессии).

**Чего не бывает (физика):** объединить VRAM нескольких машин через интернет
или ускорить *один* проход диффузии нельзя — шаги последовательны, а обмен
активациями внутри шага (~0.7 ГБ на границу на шаг для Wan 14B) через WAN
занимает больше времени, чем сам расчёт. Поэтому распределяются *единицы
работы* (варианты, тайлы, сегменты, задания) — это честный и единственный
работающий способ.

## Установка (мастер)

```bat
scripts\install_master.bat
```

или вручную:

```bat
mklink /J D:\ComfyUI_windows_portable\ComfyUI\custom_nodes\comfyui-gpu-raid D:\Projects\MultiDiffusion
```

Перезапустите ComfyUI — слева появится вкладка **GPU RAID** (иконка сервера).

Зависимостей нет (только aiohttp из состава ComfyUI). Для экспорта Long Video
нужен ffmpeg: `python_embeded\python.exe -m pip install imageio-ffmpeg`
(обычно уже стоит вместе с VideoHelperSuite).

## Быстрый старт без облака (проверка на одном ПК)

1. Запустите второй инстанс ComfyUI как тестового воркера:
   ```bat
   scripts\run_local_worker.bat
   ```
   (режим CPU для теста логики: `set EXTRA_ARGS=--cpu` перед запуском)
2. В панели GPU RAID → «Добавить воркеров» вставьте:
   ```
   gpuraid://devtoken@127.0.0.1:8189?tls=0&name=local2
   ```
3. Загрузите [docs/example_workflows/stripe_sdxl.json](docs/example_workflows/stripe_sdxl.json),
   нажмите **Queue** — 8 вариантов посчитаются на двух инстансах и придут одним батчем.

## Подключение облаков

Сначала опубликуйте этот репозиторий на GitHub (ноутбуки клонируют его на
воркера) и поправьте `REPO_URL` в первой ячейке ноутбука. Альтернатива без
GitHub — приложить исходники к Kaggle как Dataset (см. ноутбук).

| Облако | Гайд | Кратко |
|---|---|---|
| Kaggle (бесплатно) | [docs/SETUP_KAGGLE.md](docs/SETUP_KAGGLE.md) | 2×T4 16 ГБ = **два** воркера с одной сессии; модели из Kaggle Datasets → старт ~3 мин; ~30 ч/нед |
| Colab Pro (платно) | [docs/SETUP_COLAB.md](docs/SETUP_COLAB.md) | L4 24 ГБ / A100; ⚠️ бесплатный Colab запрещает распределённых воркеров — только Pro/PAYG |
| RunPod / Vast / аренда | [docs/SETUP_RUNPOD.md](docs/SETUP_RUNPOD.md) | `worker_setup.sh`; публичный прокси-URL без туннеля; вариант «90 ГБ под одну модель» |

Каждый воркер в итоге даёт строку вида
`gpuraid://ТОКЕН@адрес?name=имя` — вставьте её в панель. При обрыве туннеля
нажмите **URL** у воркера и вставьте новый адрес: токен и remap сохранятся.

## Как строить workflow для страйпинга

```
CheckpointLoader ─ CLIPTextEncode ─┐
                                   ├─ KSampler ─ VAEDecode ─ GPURAID Collector ─ SaveImage
EmptyLatentImage ──────────────────┘      ▲
GPURAID Distributor (seed) ───────────────┘
```

- **GPURAID Distributor**: выход `seed` → вход `seed` KSampler (ПКМ по
  KSampler → Convert widget to input, если вход скрыт). `total_variants` —
  сколько вариантов; `min_vram_gb` — отсечка слабых воркеров.
- **GPURAID Collector**: между VAEDecode и Save/Preview. При обычном запуске —
  прозрачный passthrough.
- Сид варианта i = `seed + i` — результат воспроизводим при любом составе воркеров.
- Тонкости, пресеты моделей для T4 и таблица min_vram: [docs/WORKFLOWS.md](docs/WORKFLOWS.md).
- Long Video: [docs/LONGVIDEO.md](docs/LONGVIDEO.md).

## Панель

- **Режимы**: политика питания воркеров (⚡/🌙/⏻/🏠), карточки-пресеты с
  примерами workflow, настройки LLM для Сценариста, gist-автоподключение и
  секреты (ключи хранятся локально, в интерфейс не возвращаются).
- **Воркеры**: статус, GPU/VRAM, задержка, бейдж платформы; 📌 (не гасить
  автостопом), «⏻» (остановить рантайм), «Проверить» — сверка моделей и нод
  воркера с текущим workflow, кнопки remap и «Скачать на воркера»
  (HF/Civitai URL, в каталоге есть все 4 файла MiniMax H3).
- **Задания**: прогресс по юнитам и воркерам, отмена.
- **Сценарист**: сюжет → план → редактор кадров и сегментов.
- **Pipeline**: анализ текущего workflow → раскладка стадий по GPU → запуск.
- **Offload**: выбрать воркера → «Запустить текущий workflow». Также в меню:
  Extensions → GPU RAID → Run on worker…
- **Long Video**: композер + список проектов + редактор сегментов
  (промпты правятся и персистятся, проект можно удалить целиком).
- **История**: счётчики юнитов по воркерам и время — виден реальный вклад каждой GPU.

## Безопасность

- Мастер слушает только `127.0.0.1` и не туннелируется — **никогда не
  открывайте свой ComfyUI в интернет**: у ComfyUI нет аутентификации, это
  равносильно удалённому доступу к ПК.
- Воркеры: middleware требует `X-GPURAID-Token` для любых не-локальных запросов
  (запросы через туннель приходят с loopback, но несут `CF-Connecting-IP`/
  `X-Forwarded-For` — исключение для loopback на них не действует). Ноутбук
  делает self-test (ожидает 401 без токена) и при сбое автоматически поднимает
  standalone-прокси `proxy/authproxy.py`.
- UI воркера через туннель можно открыть в браузере: `https://…/?gpuraid_token=ТОКЕН`
  (поставится cookie).

## Отказоустойчивость

Юнит, потерянный из-за смерти воркера/туннеля (Kaggle-сессия, обрыв WS),
автоматически перезапускается на выживших GPU, включая локальную (до
`max_retries`, по умолчанию 2). Двойное исполнение исключено детерминированным
`prompt_id`. Обрыв WebSocket не критичен: параллельно всегда работает
поллинг `/history`.
