# Long Video: видео любой длительности из коротких сегментов

Видео-модели генерируют секунды за раз. GPU RAID собирает из таких кусков
ролик любой длины и даёт редактор для монтажа. Управление — в панели
GPU RAID → **Long Video**.

## Шаблон сегмента = ваш обычный i2v-workflow

Откройте на канвасе рабочий image-to-video workflow (Wan 2.2 i2v, LTX и т.п.)
и пометьте ноды **заголовками** (ПКМ по ноде → *Title*):

| Заголовок | Нода | Обязательно |
|---|---|---|
| `GPURAID:START_IMAGE` | LoadImage стартового кадра | да (если LoadImage один — найдётся сам) |
| `GPURAID:END_IMAGE` | LoadImage конечного кадра | для режима keyframes (FLF2V) |
| `GPURAID:PROMPT` | нода с текстом промпта | нет |
| `GPURAID:VIDEO_OUT` | VHS_VideoCombine / SaveVideo | если Save-нода одна — найдётся сама |

Длительность/fps сегмента задаются самим workflow (length, frame_rate) — GPU
RAID их не трогает, он подменяет только картинки, промпт, сид и имя файла.

## Режим chain — неограниченная длина

Каждый следующий сегмент стартует с **последнего кадра** предыдущего
(классическое i2v-продолжение): укажите число сегментов и, по желанию,
промпт на каждый (по строке в textarea). Сегменты считаются последовательно —
на самом быстром доступном воркере (локальная GPU в приоритете); упавший
сегмент автоматически уходит другому воркеру. 10 сегментов по 5 секунд =
50-секундный ролик.

Особенность: качество может плавно «дрейфовать» от сегмента к сегменту
(свойство всех i2v-продолжений). Лечится перегенерацией неудачного сегмента
с другим сидом в редакторе.

## Режим keyframes — параллельно («торрент по сегментам»)

Подготовьте **ключевые кадры** (сгенерируйте картинки-опоры и положите их в
input, например через обычный страйпинг) и перечислите имена файлов по строке.
Каждый сегмент — это FLF2V-интерполяция «от ключа i к ключу i+1», сегменты
**независимы** и разлетаются по всем воркерам одновременно, как чанки
торрента. Нужен workflow с first-last-frame-кондиционированием (Wan FLF2V /
WanVideoWrapper с start+end image) и помеченным `GPURAID:END_IMAGE`.

N-1 сегментов на K GPU → почти K-кратное ускорение всего ролика.

## Редактор

Панель → Long Video → Проекты → **Редактор**:

- превью каждого сегмента (`<video>`), порядок ↑/↓, исключение;
- трим (`in`/`out`, сек) на сегмент;
- **заново** — перегенерация сегмента с новым сидом (файл заменяется на месте);
- **Экспорт**: без тримов и кроссфейда — мгновенная склейка без
  перекодирования (`ffmpeg concat`); с тримами/кроссфейдом — пересборка
  libx264 CRF 18. Итог: `output/gpuraid/<проект>/<проект>_final.mp4`.

Проекты живут в `output/gpuraid/<имя>/` вместе с `manifest.json` — редактор
работает и после перезапуска ComfyUI, шаблон сегмента хранится в манифесте
(канвас для перегенерации не нужен).

ffmpeg берётся из imageio-ffmpeg или PATH
(`python_embeded\python.exe -m pip install imageio-ffmpeg`).
