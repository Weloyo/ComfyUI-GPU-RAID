# «Сценарист»: сюжет → видео любой длительности

Пишете сюжет — LLM (или эвристика) разбивает его на сегменты, воркеры
параллельно рендерят ключевые кадры и FLF2V-сегменты, результат склеивается
в одно видео. Всё редактируется до и после рендера.

## Как это устроено

```
сюжет ──LLM──► план (N сегментов + N+1 ключевых кадров, промпты редактируемы)
                 │
                 ├─ кадры: T2I-шаблон, параллельно на всех GPU
                 │   (кадр i — конец сегмента i-1 И начало сегмента i → непрерывность)
                 ├─ сегменты: FLF2V(кадр i, кадр i+1), параллельно на всех GPU
                 └─ склейка: concat без перекодирования / экспорт с тримами и кроссфейдом
```

Проект живёт в `output/gpuraid/<label>/manifest.json` — переживает рестарты;
перегенерация любого кадра/сегмента работает без открытого канваса.

## Быстрый старт

1. Загрузите пример: панель GPU RAID → Режимы → **«♾️ Бесконечное видео»**
   (MiniMax H3), или соберите свой шаблон сегмента:
   - два `LoadImage` с заголовками **GPURAID:START_IMAGE** и **GPURAID:END_IMAGE**
     (ПКМ по ноде → Title) — Сценарист сам подставит в них ключевые кадры;
   - нода с промптом сегмента — заголовок **GPURAID:PROMPT** (в примере это
     сам `MiniMaxH3ImageToVideo`);
   - Save-нода видео (найдётся сама, или пометьте **GPURAID:VIDEO_OUT**);
   - `GPU RAID Видео-спека` → width/height/length видео-ноды: тогда Сценарист
     сможет менять длительность каждого сегмента.
2. Заполните ноду **GPU RAID Сценарист (раскадровка)** — сюжет, число
   сегментов (0=авто), длительность сегмента, аспект — и нажмите **«План ▶»**
   в теле ноды (или **Queue**: пока включён виджет `on_queue`, он делает то же
   самое вместо локального рендера).
3. Прямо в ноде появится раскадровка: правьте промпты кадров и сегментов,
   затем **«Кадры ▶»** → проверьте кадры → **«Сегменты ▶»** (или сразу
   **«Всё ▶»**). Готовый ролик собирается кнопкой **«Экспорт»** внизу ноды.
   Старый проект можно подцепить к ноде выпадашкой «проект:» или кнопкой
   «Открыть на канве» в панели (раздел «Проекты видео»).

## LLM

Настройки в панели (Режимы → Настройки LLM) — это глобальная настройка, а не
свойство проекта: любой OpenAI-совместимый
endpoint — Ollama (`http://127.0.0.1:11434/v1`), LM Studio
(`http://127.0.0.1:1234/v1`), OpenRouter, DeepSeek… Ключ хранится локально в
`user/default/gpu-raid/secrets.json` и никуда не отдаётся.

Без LLM (галка use_llm или недоступный endpoint) сюжет режется эвристикой по
предложениям/абзацам — план тот же, просто промпты стоит причесать руками.

## Шаблон ключевых кадров

По умолчанию используется встроенный SDXL T2I-шаблон
(`sd_xl_base_1.0.safetensors`, есть в каталоге «Скачать на воркера»). Свой
шаблон: соберите любой T2I-workflow на канве (нода промпта —
**GPURAID:PROMPT**, выход — единственный SaveImage или маркер
**GPURAID:KEYFRAME_OUT**) и нажмите «Шаблон кадра из канвы» в редакторе
проекта.

Кадры рендерятся строго в разрешении канвы сегментов: H3 компонует первый кадр
растяжением, а последний — кадрированием, и при другом аспекте стык между
сегментами был бы виден. Размер прописывается в `Empty*Latent*`-ноды шаблона.

## Правки после рендера

- промпт/сид сегмента → «Сохранить» (без рендера) или «заново» (перерендер);
- промпт/сид кадра → «заново»: смежные готовые сегменты помечаются
  **«кадр изменён»** — перерендерите их кнопкой «Рендер сегментов ▶»
  (она берёт только неготовые и устаревшие);
- порядок/исключение/тримы/кроссфейд персистятся в манифест;
- «Экспорт» пересобирает финальное видео с учётом правок.
